# icsi418-PA4
ICSI 418 fourth programming assignment

features:
-login, signup and creation of projects. as well as the ability to add and remove project members
-allows for the creation of user stories for a project and their title, description, priority level, and assigned members.
-able to edit the stories associated with projects
backlog view of each project via "view details"

how-to for the app-
server port 9000

CD Server-
npm install
npm run dev


Client-
cd client
npm install
npm run dev

open the printed url


To gather test data:
-Sign up 3 users
-create two different projects with seperate leads
-In project members add user1 to the first project, and user2 to the second. 
-in the backlog create stories at least five in each project. then edit their statuses. 
-check to user2 is in project 1
-make sure removing leads from their projects fails
-make sure assigning a story does not block a user from being removed from a project
